# Python---Calculator
Proiect pentru evaluarea expresiilor matematice complexe

Acest proiect implementează clasa Calculator, având funcționalitatea împărțită în două metode principale: eval (care calculează valoarea numerică a unui șir de caractere) și loop (care permite evaluarea continuă a liniilor citite de la tastatură până la comanda quit).

Programul suportă operatorii matematici de bază (+, -, *, /) și utilizarea parantezelor, respectând ordinea uzuală a operațiilor. De asemenea, gestionează spațiile albe și cifrele introduse de utilizator.

În cazul în care expresia nu poate fi evaluată, programul aruncă o excepție personalizată de tipul CalculatorException. Întreaga logică este implementată manual, fără a utiliza funcția eval() sau alte librării predefinite din Python.
